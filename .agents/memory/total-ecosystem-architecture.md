name: Total autonomous ecosystem architecture

The Total Autonomous Ecosystem is an opt-in additive layer under `ecosystem/`. Its engine composes multimodal ingestion, tool/provider abstractions, cognition and digital-twin simulation, universal memory, evolution, security, governance/routing, and hierarchical swarm recovery.

**Why:** The project needs one production-shaped composition point while preserving legacy infrastructure and allowing deployment-specific integrations to be injected rather than hardcoded.

**How to apply:** Use deterministic local implementations for verification, inject real MCP/browser/code/database/model/TEE providers in production, require approval for sensitive plans, and keep unavailable external capabilities explicit instead of silently simulating them.
