الجزء 1: محرك الـ Skills (Core Engine)
═══════════════════════════════════
ملف جديد src/lib/skillsEngine.ts:
- type Skill { id, name, description, triggers: string[], instructions: string, source: "browse"|"created-with-ai"|"manual"|"uploaded", isCustom: boolean, linkedFileIds?: string[], createdAt, updatedAt, lastUsedAt }
- getAllSkills() — يدمج السكيلز الجاهزة (من ClaudeSkillsModal الحالي) + السكيلز المخصصة المخزّنة في localStorage تحت مفتاح جديد "mr7-ai-custom-skills"
- saveSkill(skill), updateSkill(id, patch), deleteSkill(id), getSkill(id)
- matchSkills(userMessage: string): Skill[] — مقارنة كلمات الرسالة (lowercase) مع triggers[] و description، ترجع أفضل 1-3 تطابقات، وتحدّث lastUsedAt لكل تطابق
- buildSkillsAddendum(activeSkills: Skill[]): string — نص يُضاف لآخر الـ system prompt بصيغة "SKILL ACTIVATED: [name] — [instructions]" لكل سكيل مفعّل

الجزء 3: واجهة Skills بشكل Claude الرسمي (UI)
═══════════════════════════════════
عدّل/وسّع تبويب Skills الحالي في ClaudeSkillsModal.tsx (إضافة فقط) ليطابق شكل Claude بالتفصيل:

هيدر: عنوان "Skills" + أيقونة بحث + زرين:
  • زر "Browse" → يفتح المكتبة الجاهزة الحالية (السكيلز المبنية مسبقاً)
  • زر "Add ▾" → dropdown فيه 3 خيارات بالضبط:

  1) "Create with Claude" (أيقونة chat bubble):
     نافذة محادثة مصغّرة، المستخدم يشرح بلغة عادية إيه اللي عايز الـ Skill يعمله، ويُستخدم streamChat الموجود بالفعل لتوليد SKILL.md كامل (name + description بصيغة YAML frontmatter + التعليمات) تلقائياً، مع معاينة قبل الحفظ عبر saveSkill()

  2) "Write skill instructions" (أيقونة clipboard):
     فورم يدوي: حقل اسم، حقل وصف (يُستخدم كـ trigger)، صندوق نص كبير للتعليمات الكاملة → يُحفظ عبر saveSkill()

  3) "Upload a skill" (أيقونة رفع) → مكوّن جديد UploadSkillModal.tsx:
     - صندوق drag-and-drop بأيقونة مجلد+ ونص "Drag and drop or click to upload"
     - شروط الملف موضّحة تحت الصندوق: ".md file must contain skill name and description formatted in YAML" و ".zip or .skill file must include a SKILL.md file"
     - رفع .md: اقرأ YAML frontmatter (بين ---) واستخرج name و description، والباقي instructions
     - رفع .zip/.skill: فك الضغط في المتصفح بمكتبة jszip، دوّر على SKILL.md بالداخل واستخرج نفس البيانات، واحفظ أي ملفات إضافية بالأرشيف في نظام الملفات (الجزء 4) وسجّل ربطها في linkedFileIds
     - أخطاء الرفع تظهر كرسالة واضحة تحت الصندوق

قائمة الـ Skills: جدول بعمودين "Skill" و"Last used" بدل البطاقات الحالية، كل صف قابل للضغط لفتح تفاصيل السكيل (تعديل/حذف)، بخلفية بيضاء وحدود رمادية فاتحة بسيطة (زي واجهة Claude الأصلية)، بينما باقي مودالز التطبيق تفضل بستايلها الحالي.
